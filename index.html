OpenScite

用 DOI、PMID 或論文標題進行引用查找與 citation context（引用語境）分析。 請先完成 Academic Mode 確認，再開啟 OpenScite。

NUU Academic Mode 流程

01 · 官方登入開啟聯大 SSL VPN，直接向校方驗證。
02 · 建立連線依聯大官方流程完成 VPN 連線。
03 · 手動確認瀏覽器無法可靠判斷 OS 層 VPN，所以由你勾選確認。
04 · OpenScite解鎖 OpenScite，進行合法授權範圍內的文獻分析。
安全邊界：本站不偽造 NUU IP、不繞過付費牆或 DRM、不收集校方登入資料。 出版社全文是否可下載，仍由 NUU 的實際訂閱與出版社授權決定。

一般 VPN 部署狀態

目前狀態：尚未部署 VPN Backend（VPN 後端）。 GitHub Pages 只能提供靜態網站，不能執行 WireGuard Server（WireGuard 伺服器）。 等之後把 `freevpn/` 專案部署到 Linux VPS，再把這裡接到實際後端即可。
